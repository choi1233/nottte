# nottte 설치 방법

## 1. GitHub Pages에 올리기 (처음 한 번)
1. github.com에서 새 저장소(Repository)를 만들어요. 이름 예: `nottte`, 공개(Public).
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓아요.
   (index.html, manifest.webmanifest, sw.js, icons 폴더, fonts 폴더)
3. **Commit changes**를 눌러요.
4. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 고르고 Save.
5. 1~2분 뒤 `https://내아이디.github.io/nottte/` 주소가 생겨요.

## 2. 폰에 설치하기
- 아이폰: **사파리**로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: **크롬**으로 주소를 열고 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

## 3. 업데이트할 때
1. 바뀐 파일만 저장소에 다시 올려요(같은 이름으로 덮어쓰기).
2. `sw.js` 맨 위의 `nottte-v1`을 `nottte-v2`처럼 숫자를 하나 올려요.
3. 폰에서 앱을 껐다 켜면 새 버전이 적용돼요.

사진과 기록은 폰 안에 따로 저장돼 있어서 업데이트해도 그대로 남아요.

## 꼭 알아둘 것
- **주소를 바꾸지 마세요.** 기록은 주소별로 저장돼요. 저장소 이름이나 아이디가 바뀌면 빈 앱이 돼요.
- **아이폰에서 홈 화면 앱을 삭제하면 기록도 같이 지워져요.** 지우기 전에 ··· 메뉴의 **백업 내보내기**를 먼저 하세요.
- 가끔 백업 내보내기를 해두면 폰을 바꿔도 **백업 불러오기**로 그대로 옮길 수 있어요.

# 안드로이드 앱(APK)으로 받기

저장소를 GitHub에 올리면 **GitHub가 자동으로 APK를 만들어줘요.** (`.github/workflows/android.yml`)

1. github.com에서 저장소를 열고 위쪽 **Actions** 탭을 눌러요.
2. **안드로이드 APK 만들기**가 돌고 있어요. 5~10분 기다리면 초록 체크가 떠요.
3. 그 줄을 눌러 들어가면 아래 **Artifacts**에 `nottte-apk`가 있어요. 눌러서 받아요(zip 안에 `app-debug.apk`).
4. 폰으로 APK를 옮겨서(카톡 나에게 보내기, 구글 드라이브 등) 눌러 설치해요.
   - "출처를 알 수 없는 앱" 경고가 뜨면 → 설정 → 이 출처 허용을 켜요.
   - Play 프로텍트 경고가 뜨면 → "무시하고 설치"를 눌러요. 직접 만든 앱이라 뜨는 경고예요.

업데이트할 때는 파일을 고쳐 Commit → Push origin만 하면 새 APK가 또 만들어져요.
`signing/debug.keystore`는 앱의 서명 열쇠예요. **지우거나 바꾸지 마세요.** 이게 바뀌면 새 APK를 덮어 설치할 수 없어서, 앱을 지우고 다시 깔아야 해요(그러면 기록도 지워져요).
새 APK를 기존 앱 위에 설치하면 **기록은 그대로 남아요.** (앱을 삭제하면 기록도 지워지니, 삭제 전엔 백업 내보내기를 하세요.)

참고: 웹 주소(GitHub Pages)로 설치한 nottte와 APK로 설치한 nottte는 기록이 따로예요. 하나만 쓰거나, 백업 내보내기 → 불러오기로 옮기세요.
